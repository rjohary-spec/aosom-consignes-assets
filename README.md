# AOSOM — Images publiques des consignes

Ce dépôt héberge les images publiques de l’application AOSOM Signature des consignes.

## Confidentialité

Tout fichier ici est public sur Internet. Ne jamais publier de données clients, agents, commandes, e-mails, identifiants internes, secrets ou captures confidentielles. Recadrer ou flouter avant tout ajout.

## Dossier et noms

Déposer les fichiers dans `images/consignes/`. Utiliser des noms en minuscules, sans espace ni accent, par exemple `retour-produit-etape-01.webp`.

## URL HTML directe

```text
https://raw.githubusercontent.com/rjohary-spec/aosom-consignes-assets/main/images/consignes/NOM-DU-FICHIER.webp
```

```html
<img src="URL_BRUTE" alt="Description" style="display:block;max-width:100%;height:auto;margin:16px auto;">
```

Ne pas utiliser une URL contenant `/blob/` dans `src`.

Formats recommandés : WebP/JPEG pour les captures, PNG pour la transparence, largeur 800–1200 px, poids inférieur à 500 Ko.
